Getting Started

Prerequisites

- Node.js version compatible with the project's framework.
- npm, pnpm, or the package manager specified by the repository.
- Git for version control.

Clone the Repository

git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <YOUR_PROJECT_FOLDER>

Install Dependencies

For npm:

npm install

For pnpm:

pnpm install

Use the package manager corresponding to the lockfile already present in the repository.

Start Development Server

For npm:

npm run dev

For pnpm:

pnpm dev

Open "http://localhost:3000" if the development server uses the default Next.js port.

Build for Production

For npm:

npm run build
npm run start

For pnpm:

pnpm build
pnpm start

These commands apply if the project is configured as a Next.js application. Follow the existing "package.json" scripts if the repository uses a different framework or build setup.

Design Philosophy

My portfolio aims to combine engineering and creativity.

- Cinematic Design: Motion-driven storytelling instead of conventional static sections.
- Interactive Experiences: Engaging interactions that encourage exploration.
- Modern Development: Component-based architecture and reusable UI elements.
- Performance Awareness: Lazy loading and efficient rendering where appropriate.
- Responsive Design: An experience adapted to different screen sizes.
- Accessibility: Keyboard navigation and support for reduced-motion preferences.
- Professional Presentation: Clear project descriptions, technical skills, and contact information.

The priority is to create a distinctive portfolio without compromising usability, accessibility, or performance.
